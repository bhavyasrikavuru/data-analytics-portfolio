Finance Analysis Dashboard

📊 Overview
An interactive Finance Analysis Dashboard built to analyze financial performance and identify key business trends across 50,000+ transaction records.

🛠️ Tools & Technologies
- Power BI Desktop
- DAX (Time Intelligence)
- Power Query (ETL)
- Data Modeling (Star Schema)

🎯 Key Analysis
- Revenue and profit performance
- Year-over-Year (YoY) analysis
- Customer and transaction insights
- KPI monitoring
- Interactive filtering and drill-through analysis
